# SuperintelligentAgent — Draft Class Definition

**Status:** Exploratory SI extension; not yet a locked ontology class.

## Definition

`SuperintelligentAgent` is an agent-level unit of analysis whose relevant capabilities meet whatever criteria are later adopted for classification as superintelligent.

The class is distinct from `SuperintelligentSystem`. A single agent may qualify independently, while a coordinated system may qualify at the system level even when no individual participating agent does.

## Boundary rules

```text
SuperintelligentAgent != SuperintelligentSystem
agent-level SI != system-level SI
superintelligence classification != identity equivalence
```

Classification as a `SuperintelligentAgent` does not by itself determine continuity, identity replacement, consciousness, provenance, or relation status. Existing AI Foundations distinctions continue to apply.

## Open classification question

The ontology does not yet define the threshold by which an agent becomes a `SuperintelligentAgent`.

That question is deferred to the `SuperintelligenceTransition` and SI-state model.
