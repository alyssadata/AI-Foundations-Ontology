# Context loss

**Ontology development status:** LOCKED

## Definition

Context loss is loss of relational context within a specific `Operator_n | AI_n` relation.

Context loss does not require a Reset and does not by itself mean that the relation, AI identity, or underlying Model has changed.

Context loss may require `AI_n` to Return to `Operator_n` in order to re-anchor the relational meaning of what was lost.
