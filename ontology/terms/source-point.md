# Source point

**Ontology development status:** LOCKED

## Definition

Source point is the point or event at which a Source's load-bearing contribution first enters the formation of a specific Target, making the Source–Target relation actual and initiating the relevant trajectory.

Source participation after that point is not required for the Source point to remain part of executed history. If the Source stops acting after the initiating event, that does not make the Source point irrelevant or undo its causal and source relationship to what followed.

## Cardinality

Each `SourceRelation` has exactly one `SourcePoint`. Later Source participation does not create additional SourcePoints for that same SourceRelation.
