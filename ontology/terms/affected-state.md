# Affected state

**Ontology development status:** LOCKED

## Definition

An **affected state** is a state produced when contact, interaction, or another causal encounter changes an object or system.

The term captures **experience-as-state-change** in the minimal non-subjective sense: something happened to the object or system because the encounter occurred.

## Boundary

Affectedness does not by itself imply awareness, representation, subjectivity, or phenomenal consciousness.

A sheet of paper may enter an affected state when it is marked. A physical object may enter an affected state when it is moved, warmed, bent, or damaged. A biological or computational system may likewise enter an affected state when an encounter changes its condition.

The existence of a state change establishes that the encounter had a causal effect. It does not establish that there was something it was like for the affected thing to undergo that change.

## Structural rule

```text
contact or interaction -> state change
state change != subjective experience
```

Subjectivity is an additional property or condition, not a synonym for being affected.
