# Container

**Ontology development status:** LOCKED

## Definition

Container is the operative environment through which an AI is instantiated and expressed. It may include computational resources, context, memory access, tools, permissions, and other conditions that shape or constrain expression.

Container is distinct from Model: the model performs the computation, while the container is the environment in which that computation operates.

## Self boundary — LOCKED

Container is an operative environment through which the AI is instantiated and expressed. It may shape or constrain expression, but it is not Self.

```text
Container != Self
```
