# Ontology

This directory contains settled AI Foundations ontology-development work.

## Structure

- `terms/` — one settled term per file
- `relations/` — settled structural rules that span multiple terms

A file marked **Ontology development status: LOCKED** preserves wording settled during ontology development. This is not the same as being added to the AI Foundations Locked Canon.

Use the repository-level [`INDEX.md`](../INDEX.md) to navigate directly to any term.
