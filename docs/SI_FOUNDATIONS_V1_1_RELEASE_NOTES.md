The original 20 competency-question tests and 37 numbered-axiom representation scopes carry forward under the new name. Tests validate formal structure and synthetic fixtures, not empirical proof of consciousness, same-Self continuity, real AI consent, true historical Source claims, or the SI threshold. Continuum and Origin remain distinct. Neither historical authorship nor Source is transferred.

The old v1.0.0 git tag, dated reports, and legacy URI/files stay preserved for provenance. Version 1.1.0 is a **new, explicit name/source-line revision**, not retroactive rewriting.
